# 作品集图片文件夹
# ──────────────────────────────────────────────────────────
# 把你的作品截图放到这里，然后在 src/data.ts 里更新 image 路径。
#
# 支持格式：PNG  /  JPG  /  GIF  /  WebP  /  SVG
#
# 示例命名（自由命名即可）：
#   project-01.png
#   fintech-dashboard.gif
#   eco-brand.jpg
#
# 在 src/data.ts 中引用方式：
#   image: '/portfolio/project-01.png'
#   image: '/portfolio/fintech-dashboard.gif'
#
# GIF 提示：
#   - 浏览器会自动循环播放 GIF，无需额外代码
#   - 建议 GIF 文件 < 5MB，否则首帧加载会卡顿
#   - 如需控制播放，可改用 WebP 动图（更小体积）
# ──────────────────────────────────────────────────────────
